# Shipment Risk Intelligence Platform

AI-powered shipment risk scoring system — predicts delivery failures, fraud, and package loss before label creation.

## Tech Stack
ML: XGBoost, LightGBM, SHAP, scikit-learn, Optuna
API: FastAPI, Pydantic v2
MLOps: MLflow, GitHub Actions, Docker Compose
Monitoring: Prometheus, Grafana
Dashboard: Streamlit, Plotly

## Quick Start
git clone <your-repo-url>
cd shipment-risk-platform
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt -r requirements-dev.txt
